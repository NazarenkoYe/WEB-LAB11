# University API — Node.js та PostgreSQL

## 1. Опис проєкту

**University API** — це REST API для управління інформацією про студентів університету, розроблений за допомогою Node.js, Express та PostgreSQL.

API дозволяє отримувати список студентів, переглядати інформацію про окремого студента, додавати нових студентів, оновлювати їхні дані та видаляти записи з бази даних.

## 2. Використані технології

- **Node.js** — середовище виконання JavaScript.
- **Express.js** — фреймворк для створення вебсервера та REST API.
- **PostgreSQL** — система управління реляційними базами даних.
- **pg** — бібліотека для підключення Node.js до PostgreSQL.
- **dotenv** — бібліотека для роботи зі змінними середовища.
- **Postman** — інструмент для тестування API-запитів.

## 4. Налаштування бази даних PostgreSQL

Для роботи проєкту використовується база даних `university`.

Створення таблиці `students`:

```sql
CREATE TABLE students (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    age INTEGER NOT NULL,
    major VARCHAR(100) NOT NULL
);
```

Додавання початкових записів:

```sql
INSERT INTO students (name, age, major)
VALUES
    ('John Doe', 20, 'Computer Science'),
    ('Jane Smith', 22, 'Mathematics'),
    ('Alice Johnson', 21, 'Physics'),
    ('Bob Brown', 23, 'Engineering');
```

Перевірка даних у таблиці:

```sql
SELECT * FROM students;
```

## 5. Налаштування підключення до бази даних

Параметри підключення до PostgreSQL зберігаються у файлі `.env`:

```env
DB_HOST=localhost
DB_PORT=5432
DB_USER=postgres
DB_PASSWORD=your_password
DB_NAME=university
```

Замість `your_password` необхідно вказати пароль користувача PostgreSQL.

У файлі `db.js` за допомогою бібліотеки `pg` створюється пул з'єднань із базою даних. Для завантаження параметрів використовується бібліотека `dotenv`.

Файл `.env` містить конфіденційну інформацію, тому він виключений із Git за допомогою `.gitignore`.

## 6. Встановлення та запуск проєкту

### Крок 1. Встановлення Node.js

Завантажити Node.js можна з офіційного сайту:

https://nodejs.org/

Перевірити встановлення:

```bash
node -v
npm -v
```

### Крок 2. Встановлення залежностей

Відкрити термінал у папці проєкту та виконати:

```bash
npm install
```

### Крок 3. Налаштування PostgreSQL

Необхідно переконатися, що:

- PostgreSQL встановлений і запущений.
- Створена база даних `university`.
- Створена таблиця `students`.
- Додані початкові записи.
- У файлі `.env` вказані правильні параметри підключення.

### Крок 4. Запуск сервера

Для запуску сервера виконайте:

```bash
node server.js
```

Після успішного підключення до бази даних у консолі з'являться повідомлення:

```text
Server is running on http://localhost:3000
Connected to PostgreSQL database
```

Сервер готовий приймати HTTP-запити.

## 7. Реалізовані API-маршрути

У проєкті реалізовано п'ять маршрутів для виконання CRUD-операцій.

| HTTP-метод | Маршрут | Призначення |
|---|---|---|
| GET | `/api/students` | Отримання списку всіх студентів |
| GET | `/api/students/:id` | Отримання студента за ID |
| POST | `/api/students` | Додавання нового студента |
| PUT | `/api/students/:id` | Оновлення інформації про студента |
| DELETE | `/api/students/:id` | Видалення студента за ID |

### 7.1. GET — отримання всіх студентів

**Запит:**

```http
GET http://localhost:3000/api/students
```

Повертає список усіх студентів із таблиці `students`.

### 7.2. GET — отримання студента за ID

**Запит:**

```http
GET http://localhost:3000/api/students/1
```

Повертає інформацію про студента з ідентифікатором `1`.

Якщо студента не знайдено, сервер повертає статус `404 Not Found`.

### 7.3. POST — додавання нового студента

**Запит:**

```http
POST http://localhost:3000/api/students
```

У тілі запиту необхідно передати JSON:

```json
{
    "name": "Michael Wilson",
    "age": 22,
    "major": "Information Technology"
}
```

Сервер додає нового студента до бази даних і повертає створений запис.

### 7.4. PUT — оновлення інформації про студента

**Запит:**

```http
PUT http://localhost:3000/api/students/1
```

Приклад JSON для оновлення:

```json
{
    "name": "John Doe Updated",
    "age": 21,
    "major": "Software Engineering"
}
```

Сервер оновлює інформацію про студента з відповідним ID.

### 7.5. DELETE — видалення студента

**Запит:**

```http
DELETE http://localhost:3000/api/students/1
```

Видаляє студента з ідентифікатором `1` та повертає повідомлення про успішне видалення.

## 8. Обробка помилок

У проєкті реалізовано обробку помилок під час роботи з API та базою даних.

Використовуються такі HTTP-статуси:

| Код | Назва | Опис |
|---|---|---|
| 200 | OK | Запит успішно виконано |
| 201 | Created | Студента успішно створено |
| 400 | Bad Request | Некоректні вхідні дані або ID |
| 404 | Not Found | Студента не знайдено |
| 500 | Internal Server Error | Помилка сервера або бази даних |

Для SQL-запитів використовується параметризована передача значень (`$1`, `$2` тощо), що допомагає захистити застосунок від SQL-ін'єкцій.

## 9. Тестування API

Для перевірки роботи API використовується Postman.

Базова адреса сервера:

```text
http://localhost:3000
```

Приклади запитів для тестування:

| Метод | URL | Очікуваний результат |
|---|---|---|
| GET | `/api/students` | Список усіх студентів |
| GET | `/api/students/1` | Інформація про студента |
| POST | `/api/students` | Створення нового студента |
| PUT | `/api/students/1` | Оновлення даних студента |
| DELETE | `/api/students/1` | Видалення студента |

Для запитів POST та PUT потрібно вибрати в Postman вкладку **Body → raw → JSON** та передати відповідні дані.

## 10. Висновок

Під час виконання лабораторної роботи було розроблено REST API для управління даними студентів університету з використанням Node.js, Express та PostgreSQL.

Було створено базу даних `university`, таблицю `students` та налаштовано підключення до неї за допомогою бібліотеки `pg`. Для зберігання параметрів підключення використано файл `.env`.

Реалізовано основні CRUD-операції: створення, читання, оновлення та видалення записів. Також додано перевірку вхідних даних та обробку помилок.

Працездатність API перевіряється за допомогою Postman. У результаті роботи отримано практичні навички розробки серверних застосунків, роботи з PostgreSQL та створення RESTful API.
